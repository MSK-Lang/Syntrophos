# Syntrophos

Syntrophos is an intelligence layer that connects knowledge, tools, and AI into a single operating system.

## Repository layout

- `apps/` contains product applications, including the API service and future web and desktop clients.
- `packages/` contains shared capabilities and domain packages.
- `docs/` contains product and technical documentation.
- `scripts/` is reserved for repository automation.
- `examples/` is reserved for example projects and usage samples.
- `.github/` is reserved for GitHub configuration.
