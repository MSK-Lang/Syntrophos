

## Overview

Syntrophos consists of six primary layers.

User

↓

Frontend

↓

Backend API

↓

Memory Engine

↓

AI Engine

↓

Knowledge & Tool Layer

---

## Frontend

Responsible for:

- Chat interface
- Dashboard
- Search
- Notes
- Tasks
- Settings

---

## Backend API

Responsible for:

- Authentication
- User management
- Tool execution
- Orchestration
- Synchronization

---

## Memory Engine

Responsible for:

- Retrieval
- Entity extraction
- Embeddings
- Knowledge graph
- Obsidian synchronization

---

## AI Engine

Responsible for:

- Reasoning
- Planning
- Summarization
- Research
- Agent coordination (future)

---

## Knowledge & Tool Layer

Integrates with:

- Obsidian
- GitHub
- Calendar
- Gmail
- Local files
- Browser
- Future plugins

---

## Data Flow

1. User submits input.
2. Relevant memories are retrieved.
3. AI reasons over context.
4. Tools execute when required.
5. Results are returned.
6. Permanent knowledge is written back into Obsidian.
