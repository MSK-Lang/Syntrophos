# AI Chat

## Purpose

The primary interface for interacting with Syntrophos.

Instead of searching through notes manually, users can ask questions, request actions, and collaborate with their knowledge base.

---

## MVP

- Natural language chat
- Uses Obsidian context
- Semantic search
- Tool calling
- File references


# Reasoning Engine

## Purpose

Syntrophos doesn't simply retrieve information.

It synthesizes information from multiple sources to help users make decisions and complete work.

## Capabilities

- Cross-note reasoning
- Project awareness
- Goal-aware planning
- Timeline understanding
- Conflict detection
- Decision support
- Context-aware recommendations

## Example

User:
"What should I work on today?"

Syntrophos considers:

- Calendar
- Deadlines
- Active projects
- Energy level (future)
- Recent progress
- Previous decisions
- Long-term goals

before generating a plan.
